# 自由对话交互与界面

## 使用流程

- 自由对话沿用原有浅绿风格，合并侧栏只用于自由对话，其他模块保留现有导航。
- 已保存伙伴打开最近一段有消息的聊天；历史可按伙伴和消息搜索，也可查看回收站。
- 预设伙伴直接进入准备界面，首次发送消息或开始语音时自动加入“我的对话伙伴”。仅浏览不创建练习、不启动麦克风、不调用模型。
- 新对话保存独立草稿；用户可继续上一段聊天，未发送内容按账号、对话或新草稿隔离。
- 修改伙伴设置后，从下一段新对话生效；已有聊天继续使用原快照。

## 布局

聊天正文和底部操作栏共用最大 680px 的阅读宽度。侧栏、消息滚动区与底部操作区分别布局。语音/文字切换、音色语速入口、接话建议和开始/继续按钮在同一操作栏；窄屏自动换行。文字输入或活动语音控制在下方展开。

随手记根据主区域实际宽度呈现：至少900px时使用280px独立列，否则使用有遮罩的模态抽屉。抽屉内部滚动，关闭后返回触发按钮；通话中保留结束语音入口。

消息保留姓名、时间、正文及独立来源。5分钟内同一片段、同一说话人的连续消息减少重复元数据。桌面消息预留工具区，正文与工具区共享连续悬停范围，避免按钮显示后失去点击能力。键盘聚焦显示工具，触屏始终显示，点击高度至少40px。

## 草稿与保存

正文和模式在输入时保存到当前浏览器，刷新、切换伙伴、重新进入后恢复。草稿含请求标识，失败可重试；服务端确认成功后才清除对应版本。草稿迁移到真实thread前先保存新键，再清理旧键。

浏览器存储不可用时保留内存内容并提示保存限制；离开时提醒。多标签页检测版本变化，保留冲突副本供恢复，不静默覆盖。此功能不提供跨设备草稿同步。

通话中切换文字或离开页面，先确认结束，再等待最后转写保存。保存失败保留消息并允许重试，取消继续通话。完成后可在同一逻辑对话中接着打字。

## 设置

保留原有伙伴名称、目的、音色、纠错方式、难度、语速及完整提示词设置。底部提供“保存修改”和“保存并新开对话”；新开对话仍不自动启动麦克风。顶部音色语速入口显示当前聊天实际使用的快照，可打开设置。

原设置末尾追加“聊天字号”下拉选项，支持16、18、20、22px，默认18px，立即应用双方消息、译文与输入框。阅读偏好按账号在当前浏览器保存，并支持多标签页同步；不改变伙伴版本或聊天快照，不触发伙伴未保存提醒。

设置正文独立滚动，标题和保存操作固定。删除重复的当前音色说明、生效范围横幅、大字号预览卡以及宣传式引导文案；保留实际连接/静音状态、错误、保存失败重试和切换/删除确认。

## 消息辅助与练习

- 听这句、翻译按需请求，结果在组件内缓存；切换聊天、开始语音或离开时停止朗读。
- 接话建议由用户主动请求，选择后只填入输入框，不自动发送。
- 收藏支持原词、原句和整段，保留真实消息与会话来源；已有收藏可查看，不通过文案猜测保存成功。
- 整段收藏在练习前选择确切句子；随手记和学习资产复用练习组件，答案草稿按用户与条目保留。
- 学习资产各分类独立加载，失败可单独重试，不显示为无收藏，也不清空其他分类。

## 验证

前端执行 `npm run test:checks`、`npm test`、`npm run build`。后端常规测试执行 `./mvnw test`，完整CI执行 `./mvnw -B -Pci-integration verify`，使用独立PostgreSQL与Redis容器。

交互回归覆盖草稿刷新恢复、预设首次保存、设置双动作、字号即时应用、模态键盘焦点、语音切换与补存失败、收藏和练习来源。布局检查覆盖桌面与390px手机视口，确认工具按钮可命中、设置可滚动。测试使用模拟AI响应，不主动调用付费模型或开启真实麦克风。
